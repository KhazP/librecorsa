# Glossary: Italian (it)

## Style
- Address the player as "tu" (informal), never "Lei". Prefer neutral wording that avoids addressing the player at all in labels.
- Buttons and actions: imperative singular (tu form) as Italian games do: "Salva", "Continua", "Riprova", "Esci", "Unisciti". Labels and menu entries are nouns ("Impostazioni", "Classifica").
- Apostrophe: always the typographic ’ (U+2019), never ASCII '. Example: "l’auto", "un’altra", "dell’asse".
- Quotes: «…» (guillemets) for quoted text; no space padding needed. Use "…" as a single character for ellipsis. No space before : ; ! ?
- Stay in English: car names, circuit names, LibreCorsa, DRS, ERS, ABS, TC, MFD, HUD, FFB, km/h, mph, rpm, S1/S2/S3, P1/P2, keyboard key names (Esc, Shift, Enter, Space, F8, Ctrl+V), controller button names (Cross, Circle, A, B, L3, R2, LB).
- Normal usage in Italian sim racing: "force feedback" is kept in English (lowercase mid-sentence, "Force Feedback" as a label is fine); "setup", "ghost", "safety car", "pit lane"-style loanwords are common; "box" is the usual word for pit lane. "Pole position", "grid"→"griglia", "drive-through" kept.
- Gender: "giro", "tempo", "settore" masculine; "gara", "pista", "classifica" feminine. Use "auto" (feminine), not "macchina" or "vettura" (vettura only in formal/class contexts).
