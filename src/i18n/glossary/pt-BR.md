# Glossary: Brazilian Portuguese (pt-BR)

## Style
- Address the player as "você" (never "tu", never European forms like "ecrã", "utilizador", "equipa"). Prefer labels that avoid addressing the player.
- Buttons and actions: infinitive as Brazilian software and games do ("Salvar", "Continuar", "Sair", "Entrar", "Tentar de novo"). Labels are nouns.
- Apostrophe: always the typographic ’ (U+2019), never ASCII '. Rare in Portuguese.
- Punctuation: quotes "…" (curly “…”); ellipsis as single "…". No space before : ; ! ?
- Brazilian spelling (post-2009 orthography): "ação", "ótimo", "arquivo", "tela", "equipe", "time".
- Stay in English: car names, circuit names, LibreCorsa, DRS, ERS, ABS, TC, MFD, HUD, FFB, km/h, mph, rpm, S1/S2/S3, P1/P2, keyboard key names (Esc, Shift, Enter, Space, F8, Ctrl+V), controller button names (Cross, Circle, A, B, L3, R2, LB).
- Normal usage in Brazilian sim racing: "force feedback" (English), "setup", "ghost", "safety car", "pit lane", "grid", "pole position" are all kept in English; "box" is also said for pit. Use "freio" (not "travão"), "câmbio" (not "caixa de velocidades"), "volante", "pneus", "tela".
