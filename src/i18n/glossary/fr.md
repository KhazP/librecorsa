# Glossary: French, France (fr)

## Style
- Address the player as "vous" (formal plural/polite), never "tu". Prefer wording that avoids addressing the player in short labels.
- Buttons and actions: infinitive ("Enregistrer", "Continuer", "Quitter", "Rejoindre", "Réessayer"). Labels are nouns.
- Apostrophe: always the typographic ’ (U+2019), never ASCII '. Example: "l’écart", "d’essai", "aujourd’hui".
- Punctuation: a no-break space (U+00A0) before : ; ! ? and inside « » (« texte »). Ellipsis as single "…". Quotes: « … ».
- Sentence case for labels; months and weekdays lowercase. Accented capitals are kept ("Échelle", "À propos").
- Stay in English: car names, circuit names, LibreCorsa, DRS, ERS, ABS, TC, MFD, HUD, FFB, km/h, mph, rpm (not tr/min), S1/S2/S3, P1/P2, keyboard key names (Esc, Shift, Enter, Space, F8, Ctrl+V), controller button names (Cross, Circle, A, B, L3, R2, LB).
- Normal usage in French sim racing: "Force Feedback" (English, often "FFB"), "setup" used in the community but "réglages" is what localized games (ACC, F1, GT7) show; use "Réglages". "Safety car" is said in English in race broadcasts but games show "voiture de sécurité"; use the French. "Pole position", "pit stop" kept in English; "stands" for pits.
- Gender: tour (m), course (f), piste (f), voiture (f), pneu (m), grille (f).
