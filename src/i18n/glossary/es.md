# Glossary: Spanish, neutral (es)

## Style
- Address the player as "tú" (never "usted", never "vos", never "vosotros"/"os" plurals). Prefer neutral labels that avoid addressing the player.
- Buttons and actions: infinitive as Spanish-language software and games do ("Guardar", "Continuar", "Salir", "Reintentar", "Unirse"). Labels are nouns.
- Neutral Spanish: avoid Spain-only words (coche, ordenador, muelles, mando, vale) and Mexico-only words. Prefer pan-regional words: "auto", "resortes", "gamepad", "neumáticos" (not "llantas"), "jugabilidad". Use "ustedes"-compatible phrasing only if a plural address is unavoidable.
- Apostrophe: always the typographic ’ (U+2019), never ASCII ' (rare in Spanish).
- Punctuation: inverted marks required (¿…? ¡…!). Quotes: «…» or "…"; use «…». Ellipsis as single "…". No space before : ; ! ?
- Capitalisation: sentence case in labels; weekdays/months lowercase.
- Stay in English: car names, circuit names, LibreCorsa, DRS, ERS, ABS, TC, MFD, HUD, FFB, km/h, mph, rpm, S1/S2/S3, P1/P2, keyboard key names (Esc, Shift, Enter, Space, F8, Ctrl+V), controller button names (Cross, Circle, A, B, L3, R2, LB).
- Normal usage in Spanish sim racing: "force feedback", "setup", "pit lane", "safety car", "pole position", "ghost" are all commonly kept in English or semi-translated ("fantasma"). Use as in the table.
