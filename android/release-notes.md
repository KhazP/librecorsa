LibreCorsa for Android: a fullscreen app that opens the live site at https://librecorsa.org/play, so it stays as current as the site. Built by GitHub Actions from this tag's source (`.github/workflows/release-android.yml`). The desktop app for Windows, macOS and Linux has its own releases: https://librecorsa.org/download.

## Download
- **Android (APK):** `LibreCorsa-*-android.apk` (Android 7+, Chrome required for fullscreen)

## Installing
Signed APK: allow installing from your browser when prompted. It verifies against `librecorsa.org/.well-known/assetlinks.json` and opens fullscreen with no URL bar. A newer APK installs over the one you have.
